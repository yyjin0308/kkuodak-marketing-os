반자동 콘텐츠 디자이너

AI는 배경만 생성합니다. 실제 꾸오닭 패키지와 한글 카피는 원본 그대로 별도 합성합니다. 이미지 생성 API 비용이 발생합니다.

배경을 생성하기 전에는 기존 템플릿이 표시됩니다. 생성된 배경은 현재 브라우저에서만 유지되므로 PNG로 다운로드하세요.

원본 패키지 4종이 포함되어 있습니다. 선택 시 원본 비율 그대로 합성합니다.

업로드한 사진은 원본 픽셀을 재생성하지 않고 캔버스에 비율 유지로 배치합니다. 배경이 투명한 PNG를 권장합니다. 업로드 이미지는 저장되지 않으므로 새로고침 시 다시 선택해야 합니다.

정확한 1080×1350 PNG 출력. 실제 사진 원본을 재생성하지 않는 템플릿 합성 방식입니다. AI 배경 생성과 원본 패키지 합성을 지원합니다. 생성 배경은 PNG로 별도 보관하세요.
